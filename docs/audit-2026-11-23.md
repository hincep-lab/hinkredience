## Další závěry auditu

| Oblast | Stav |
| --- | --- |
| Lokální data | SQLite používá oddělené databáze pro účty a samostatný hostovský soubor. Recepty mají historii, konflikty synchronizace a koš. Ruční export a obnovu ve větším rozsahu je potřeba ověřit společně s úložištěm fotek. |
| Rodina a nákupy | SQL testy pokrývají izolaci uživatelů, sdílení s domácností a oprávnění k nákupním seznamům i receptům. Pro chování dvou naráz pracujících telefonů je potřeba ověření na testovacím backendu. |
| Server | Lokálně prošlo 35 testů migrací a RLS v PGlite a 155 testů šesti Edge Functions. Kontrola typů všech šesti funkcí prošla. Testy volají makety externích služeb. |
| Závislosti | Výchozí `pubspec.lock` postrádal přímé závislosti deklarované v manifestu, mimo jiné OCR, práci na pozadí a notifikace. Řešení načtené Flutterem 3.50.0 je v této větvi zaznamenané a workflow Preview kontroluje jeho platnost. |
| Platformy | Android, iOS a web sdílí Flutter jádro. Oprávnění a implementace OCR, notifikací a souborů se liší. Web má vlastní SQLite přes WebAssembly a čte obrázky přímo ze serveru. |
| Náklady | První úpravy používají stávající nástroje a závislosti. Pro izolované zkoušky databáze a Edge Functions stačí PGlite a Deno. Preview nevyžaduje klíče Supabase ani placené AI. |

## Ověření potřebné před produkčním nasazením

- Připravit testovací kuchařku s verzemi receptů, sdílenými recepty, originály i náhledy a souběžně upraveným nákupním seznamem. Ověřit obnovu zálohy databáze i úložiště fotografií.
- Změřit studený start, první otevření seznamu receptů, hledání ve velkém seznamu a čas nutný k doplnění fotek na druhém zařízení. Výsledky porovnávat na stejných testovacích datech.
- Ověřit fotoaparát, výběr fotky, OCR, minutku na pozadí, sdílení a návrat do aplikace na Androidu. Prověřit nahrávání fotek, otevření odkazu a obnovení relace ve webové verzi na Androidu a iOS.

Prošlo 350 testů Flutteru včetně scénářů pro navigaci, prázdné filtry, zvětšené písmo, start a obnovu lokálních dat. Statická analýza nahlásila pouze informativní upozornění. Formátování a statická kontrola všech workflow prošly.

## Android Preview

GitHub Actions sestavuje APK pro arm64 po odeslání větve `codex/**`. Artefakt `hinkredience-preview-arm64` obsahuje `hinkredience-preview-arm64.apk`. Android jej identifikuje jako `cz.hink.hinkredience.preview` a zobrazuje jako **HINKredience° Test**. Testovací kuchařka začíná prázdná a ukládá data lokálně.

Stejné sestavení je možné vytvořit s Flutterem 3.50.0, Javou 21 a Android SDK.

```bash
flutter pub get --enforce-lockfile
HINKREDIENCE_PREVIEW=true flutter build apk --release --target-platform android-arm64 \
  --dart-define=HINKREDIENCE_PREVIEW=true
```
